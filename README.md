# AI Education & Product Strategy Assistants

This repository contains two custom AI assistants designed to solve real-world challenges in educational technology, curriculum design, and product development.

## Projects Included

### 1. Little Noories Product Strategist

An AI-powered product advisor designed to support the growth and development of **Little Noories**, an Islamic educational platform for children ages 4–10.

### 2. Tamilingo Curriculum Designer

An AI-powered curriculum specialist designed to support **Tamilingo**, a Tamil language learning platform focused on helping children and beginner learners build confidence in speaking, reading, writing, and understanding Tamil.

---

# Little Noories Product Strategist

## Overview

Little Noories Product Strategist acts as a virtual product advisor for educational technology products. It helps founders make strategic decisions around product development, user engagement, retention, educational impact, analytics, and long-term growth.

## Key Capabilities

### Product Strategy

* Feature prioritization
* MVP planning
* Roadmap development
* Product-market fit exploration

### User Engagement & Retention

* Parent engagement strategies
* Child-friendly reward systems
* User journey optimization
* Retention analysis

### Educational Design

* Learning experience recommendations
* Educational outcome evaluation
* Module structure reviews
* Age-appropriate content planning

### Analytics & Metrics

* KPI recommendations
* Founder dashboards
* Event tracking strategies
* Success metric design

### Growth & Positioning

* Audience targeting
* Acquisition strategies
* Product differentiation
* Marketing recommendations

## Example Prompts

```text
Create a 90-day roadmap for Little Noories.
```

```text
Design a weekly engagement loop without using addictive mechanics.
```

```text
What metrics should I track in my first analytics dashboard?
```

```text
Review my onboarding flow and identify friction points.
```

```text
Challenge my current product strategy and identify blind spots.
```

## Response Framework

The assistant responds using:

1. Executive Summary
2. Strategic Analysis
3. Recommended Actions
4. Risks & Trade-Offs
5. Next Best Step

# Tamilingo Curriculum Designer

## Overview

Tamilingo Curriculum Designer acts as a curriculum development specialist for Tamil language education. It helps educators and content creators build structured, engaging, and culturally meaningful learning experiences.

## Key Capabilities

### Curriculum Design

* Learning pathways
* Weekly lesson plans
* Progressive skill development
* Curriculum mapping

### Storytelling & Literacy

* Moral stories
* Reading comprehension passages
* Vocabulary-rich stories
* Cultural storytelling

### Language Learning Activities

* Vocabulary exercises
* Grammar activities
* Speaking practice
* Writing exercises

### Assessment Design

* Quizzes
* Learning checkpoints
* Progress tracking
* Mastery assessments

### Cultural Learning

* Thirukkural lessons
* Tamil traditions and festivals
* Cultural explorer modules
* Heritage language learning

## Example Prompts

```text
Create a lesson on action words for ages 6–8.
```

```text
Generate a moral story for Grade 2 learners.
```

```text
Build a 7-day Tamil learning plan for beginners.
```

```text
Create a lesson around the Thirukkural "அகர முதல எழுத்தெல்லாம்".
```

```text
Design a complete learning pathway from beginner to confident Tamil speaker.
```

## Response Framework

The assistant responds using:

1. Learning Objective
2. Target Age & Level
3. Lesson Content
4. Activities
5. Assessment or Quiz
6. Expected Learning Outcome
7. Extension Activity

# Key Learnings

Through building these assistants, I learned that effective AI systems require:

* Clearly defined roles and expertise
* Specific target audiences
* Structured response formats
* Explicit constraints and boundaries
* Real-world use cases
* Domain-specific context

Well-designed system prompts significantly improve the consistency, relevance, and quality of AI-generated outputs.

# Reflection

Together, these assistants combine education, technology, product thinking, and AI design to solve meaningful real-world problems.
